Welcome to SmartAssist, a universal AI helper web app designed to assist users with everyday tasks such as learning new topics, writing emails and messages, getting clear explanations, and improving productivity.

This project focuses on real-world usability, a clean chat experience, and AI-assisted development (vibe coding).

🌐 Project Info

Live URL: https://smart-assist-ai-rosy.vercel.app

✨ What SmartAssist Can Do

Answer general questions clearly and simply

Explain complex topics in an easy-to-understand way

Help write emails, messages, and short content

Provide step-by-step guidance when needed

Offer a clean, fast, and responsive chat experience

🛠️ How Can I Edit This Project?

You can edit and extend this project in multiple ways.Use Your Preferred IDE (Local Development)

If you prefer working locally:

Prerequisites

Node.js & npm installed
👉 Install using nvm: https://github.com/nvm-sh/nvm#installing-and-updating

Steps
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
